# L'atelier by S. – caisse du salon

Application web installable (PWA) pour le salon L'atelier by S. : agenda des rendez-vous, rappels SMS la veille, estimation et encaissement des prestations (espèces ou Wero), fiches clientes avec l'historique des produits utilisés, ventes du mois et tarifs modifiables.

Les données (clientes, rendez-vous, ventes) restent sur le téléphone. Elles ne sont jamais envoyées sur ce dépôt. Pensez à faire une sauvegarde depuis l'onglet Tarifs.

## Installer sur le téléphone

- **iPhone (Safari)** : ouvrir l'adresse de l'app, toucher Partager, puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvrir l'adresse de l'app, toucher le menu ⋮, puis « Installer l'application ».

## Mettre à jour

Modifier `index.html`, puis changer `VERSION` dans `sw.js` pour que les téléphones récupèrent la nouvelle version.
